流程可以记成：

1. 打开 [https://www.v2ny.vip](https://www.v2ny.vip) 尝试登录
2. 登录成功则先看套餐还在不在；还在就观察恢复，不在就带凭证找客服
3. 登录失败则先确认验证码邮件有没有被风控拦截，再考虑是否需要新账号并提交旧订单证明
4. 不要把付款截图和密码发到来路不明的「找回页」

若站点数据库停留在某个备份时间点，订单显示会和你记忆中的不一致，材料里把支付时间和金额写清楚更重要。
